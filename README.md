# Mini Hospital Emergency Management System

CIT300 - Data Structures and Algorithms

## Overview
A Java console application that demonstrates four data structures:
- Binary Search Tree (BST) for patient records
- Queue for emergency patients
- Stack for completed treatment records
- Singly Linked List for patient visit history

## Main Operations
### Patient BST
Insert, search, delete, and in-order traversal.

### Emergency Queue
Enqueue, dequeue, and display. The queue follows FIFO.

### Treatment Stack
Push, pop, and display. The stack follows LIFO.

### Patient Visit Linked List
Add, remove, search, and display visits.

## Eclipse
The project uses package `hospital`. The main class is `HospitalManagementSystem`.

## How to run
Run `HospitalManagementSystem.java` as a Java Application.

The program starts with sample data so the main data structures can be demonstrated immediately.

## Patient Management

Patient records are managed using a Binary Search Tree (BST).
Each patient is identified by a unique Patient ID. The system supports
inserting, searching, deleting, and displaying patient records using
in-order traversal.
